## 1. Anti-virus software

| Item | Yes / No / N/A |
|---|---|
| Anti-virus (anti-malware) software is installed on all devices: laptops, desktops, routers, tablets and phones [4557] | [ ] |
| Security software is set to update automatically [IR] [4557] | [ ] |
| Automatic scans are configured, and files or media from outside sources are scanned before opening [IR] | [ ] |
| Security software was downloaded from the vendor's own site, never from a pop-up or an e-mail link [IR] [4557] | [ ] |

## 2. Firewalls

| Item | Yes / No / N/A |
|---|---|
| A firewall is in use: hardware, software or both [IR] | [ ] |
| The operating system's built-in firewall is enabled, even if an external firewall is used [IR] | [ ] |
| Everyone understands that a firewall does not protect against phishing or installed malware [IR] | [ ] |

## 3. Two-factor authentication

| Item | Yes / No / N/A |
|---|---|
| Two-factor authentication is turned on for e-mail accounts [IR] | [ ] |
| Multi-factor authentication is turned on for tax software and for every password-protected product that offers it, including storage provider accounts [IR] [4557] | [ ] |
| Multi-factor authentication is implemented for anyone accessing customer information on the firm's systems [4557] [RULE 314.4(c)(5)] | [ ] |

## 4. Backup software or services

| Item | Yes / No / N/A |
|---|---|
| Critical files are routinely backed up to an external source: a cloud storage service or an external drive [IR] | [ ] |
| Backed-up taxpayer data is encrypted [IR] [4557] | [ ] |
| External backup drives are kept in a secure location, not connected full-time to a network [4557] | [ ] |

## 5. Drive encryption

| Item | Yes / No / N/A |
|---|---|
| Drive (full-disk) encryption is used on computers that hold client data [IR] | [ ] |
| Encryption also covers removable media such as thumb drives [IR] | [ ] |
| Drive encryption is used on tablets, laptops and smart phones, so data cannot be read if they are lost, stolen or improperly discarded [4557] | [ ] |

## 6. Virtual Private Network

| Item | Yes / No / N/A |
|---|---|
| An encrypted VPN is used whenever anyone connects from an unknown network or works from home [IR] | [ ] |
| Remote access to the office network uses both multi-factor authentication and a secure VPN [4557] | [ ] |
| Public Wi-Fi is not used to access business e-mail or sensitive documents [4557] | [ ] |
